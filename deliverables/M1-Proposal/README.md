# 📝 M1 - Project Proposal

M1 established the scope and plan for **Forecasting and Explaining U.S. Unemployment Through Macroeconomic Indicators**.

## 🎯 Milestone Objective

Define the unemployment-forecasting problem and research questions, identify the stakeholders, select the public data sources, and outline the proposed methods and deliverables.

## ✅ Work Completed at M1

- Framed U.S. unemployment forecasting as the primary predictive problem.
- Separated forecasting from the secondary historical-relationship question.
- Identified policymakers, researchers, workforce planners, businesses, and students as intended stakeholders.
- Selected six public macroeconomic series for the proposed dataset.
- Defined the planned data-engineering, statistical, machine-learning, visualization, and communication workflow.
- Documented ethics risks, limitations, milestones, and the Create-Observe-Analyze process.
- Established the initial project scope, Charter, Backlog, and repository organization.
